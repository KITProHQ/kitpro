# KITPro cloud

This area is reserved for optional future cloud and supporting services.

Cloud services are outside Phase 1. KITPro Server must not require a hosted control plane, a mandatory KITPro account, or cloud connectivity for installation, local management, application operation, health, logs, updates, or local recovery.

Future services may support remote management, monitoring, backup coordination, or remote access. Each service must document what data leaves the local host, how the user disables the service, and what continues to work after disconnection.

The local host remains authoritative for local infrastructure. A cloud outage or the end of a KITPro cloud service must not stop managed applications from running.
