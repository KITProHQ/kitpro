# KITPro hardware

This area is reserved for possible future KITPro hardware products.

Custom hardware and manufacturing are outside Phase 1. KITPro Server targets a supported Linux server or mini PC that the user already owns or obtains independently.

Future hardware must remain compatible with the product principles. Owning KITPro hardware must not become a requirement for access to user applications or data, and hardware-specific convenience must not create a proprietary workload format.
