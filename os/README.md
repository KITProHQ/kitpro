# KITPro OS

This area is reserved for possible future KITPro operating-system or platform work.

KITPro OS is not part of Phase 1. KITPro Server must first work on a documented, supported Linux host without requiring a KITPro operating system. No Phase 1 design may use this future area to avoid host compatibility, packaging, privilege, update, or security decisions.

Work in this area should begin only after the KITPro Server vertical slice is complete and evidence shows that an operating-system product solves needs that supported Linux distributions cannot meet cleanly.
