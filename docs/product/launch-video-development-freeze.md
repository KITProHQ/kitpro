# Launch-video development freeze

Freeze window begins 2026-09-15 and remains in effect through completion of the KeepItTechie KITPro Server launch video. This is a project-management agreement, not a technical enforcement mechanism.

## Allowed during the freeze

- Critical security fixes.
- Release-breaking bug fixes.
- Factual documentation corrections.

Any allowed change that affects a public product claim must update the [video baseline](kitpro-server-video-baseline.md) before affected narration or visuals are finalized.

## Deferred until after the video

- New catalog applications.
- New runtime architecture.
- New storage, networking, or device capabilities.
- UI or website redesigns.
- Hardware capability expansion.
- Disaster-recovery architecture work.
- Other feature expansion.

## Frozen source of truth

Use the [KITPro Server current-state brief](kitpro-server-current-state.md), [B-roll inventory](video-broll-inventory.md), [support matrix](../support-matrix.md), [known limitations](../release/known-limitations.md), and [video baseline](kitpro-server-video-baseline.md) for the production cycle.
