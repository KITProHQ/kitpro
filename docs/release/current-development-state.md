# Current development state

KITPro Server is a public alpha. The current source baseline contains the secure API/helper runtime, local-administrator authentication, a 15-application immutable catalog, single- and multi-container ownership, persistent storage, generated secrets, exact service exposure, trusted updates, Debian/Ubuntu/Arch packages, optional NVIDIA/Ollama acceleration, trusted external storage, Jellyfin, and read-only/read-write media and file applications.

The validated release candidate is 0.1.0-alpha.11. Its public source, packages, checksums, SBOM, build metadata, and release manifest are published together through the [versioned GitHub prerelease](https://github.com/KITProHQ/kitpro/releases/tag/v0.1.0-alpha.11). The release page remains authoritative for downloadable artifacts.

Read the [current product inventory](../product/current-product-inventory.md), [support matrix](../support-matrix.md), [known limitations](known-limitations.md), and versioned [alpha.11 notes](0.1.0-alpha.11-release-notes.md) for the exact boundary.
