# Current development state

KITPro Server is a public alpha. The current source baseline contains the secure API/helper runtime, local-administrator authentication, a 15-application immutable catalog, single- and multi-container ownership, persistent storage, generated secrets, exact service exposure, trusted updates, Debian/Ubuntu/Arch packages, optional NVIDIA/Ollama acceleration, trusted external storage, Jellyfin, and read-only/read-write media and file applications.

The current public version is [`v0.1.0-alpha.11`](https://github.com/KITProHQ/kitpro/releases/tag/v0.1.0-alpha.11). It is a prerelease built from source commit `1eed6b0a2199e927a9647e50206e89f6cfc19995` and includes the GPU, trusted-storage, and media/data catalog work summarized above. The published release metadata and checksums are authoritative for downloaded packages. No replacement release is needed for this documentation freeze.
