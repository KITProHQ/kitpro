# Current development state

KITPro Server is a public alpha. The current release contains the secure API/helper runtime, local-administrator authentication, a 15-application immutable catalog, durable lifecycle operations, reconciliation and repair, backup and restore recovery, persistent storage, generated secrets, exact service exposure, trusted updates, Debian and Arch packages, optional NVIDIA/Ollama acceleration, trusted external storage, Jellyfin, and read-only/read-write media and file applications.

The current public version is [`v0.1.0-alpha.12`](https://github.com/KITProHQ/kitpro/releases/tag/v0.1.0-alpha.12). It is a prerelease built from source commit `ada9555ab680613f8b56f6f0762abce6f0955670`. The published release metadata and checksums are authoritative for downloaded packages.

Read the [current product inventory](../product/current-product-inventory.md), [support matrix](../support-matrix.md), [known limitations](known-limitations.md), and versioned [alpha.12 notes](0.1.0-alpha.12-release-notes.md) for the exact boundary.
