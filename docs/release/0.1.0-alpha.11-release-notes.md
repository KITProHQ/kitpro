# KITPro Server 0.1.0-alpha.11 release notes

Alpha 11 publishes the current 15-application KITPro Server catalog for Debian
13 amd64, Ubuntu 26.04 LTS amd64, and Arch Linux x86_64 under its documented
`linux-lts`, rootful Docker, and enforcing AppArmor boundary. The polished
application interface, documentation, and screenshots now describe the same
public package baseline.

The catalog includes FreshRSS, Uptime Kuma, Mealie, Memos, Actual Budget,
Vaultwarden, Home Assistant, Paperless-ngx, Open WebUI, IT-Tools, Ollama,
Jellyfin, Navidrome, Audiobookshelf, and SFTPGo. Ollama supports CPU operation
and NVIDIA acceleration live-certified with an RTX A2000 12GB. Jellyfin is
GPU-aware, but NVIDIA transcoding is not yet certified.

Trusted external storage turns the media and data catalog into a practical
feature. Navidrome and Audiobookshelf consume administrator-approved read-only
libraries; Jellyfin consumes a read-only media library; SFTPGo is the first real
imported read-write consumer. Local and already-mounted NFS/CIFS roots are
supported, but KITPro does not mount network shares or manage their credentials.
All four applications start private by default.

Writable imported roots use a conservative single-writer policy. Another
writer, or a reader from another installation, cannot bind a root while its
writer is active. Read-only roots may be shared. KITPro never deletes imported
data with an installation.

The helper receives only `CAP_CHOWN` so it can assign the trusted non-root owner
to newly created KITPro-managed directories. It cannot choose an identity,
change imported-root ownership, inject supplementary groups, or gain broader
filesystem/device capabilities. AppArmor and package tests enforce that limit.

Immich is not included: its supported topology needs shared component secrets,
health-gated dependencies, bounded database shared memory, and database-aware
backup/rollback. Syncthing is not included because bridge networking does not
provide its supported LAN discovery topology, and host networking remains
prohibited. The archived original File Browser is replaced by maintained,
first-run-authenticated SFTPGo.

KITPro remains alpha software. AMD and Intel acceleration are not live-certified;
multi-GPU scheduling, arbitrary devices and bind mounts, host networking,
high availability, clustering, and full disaster recovery are not supported.
