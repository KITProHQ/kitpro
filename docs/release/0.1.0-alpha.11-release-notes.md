# KITPro Server 0.1.0-alpha.11 release notes

Alpha 11 turns trusted external storage into a practical media and data catalog.
Navidrome and Audiobookshelf consume administrator-approved read-only libraries;
SFTPGo is the first real imported read-write consumer. All three run as a
manifest-declared numeric non-root identity and start private by default.

Writable imported roots use a conservative single-writer policy. Another
writer, or a reader from another installation, cannot bind a root while its
writer is active. Read-only roots may be shared. KITPro never deletes imported
data with an installation.

The helper receives only `CAP_CHOWN` so it can assign the trusted non-root owner
to newly created KITPro-managed directories. It cannot choose an identity,
change imported-root ownership, inject supplementary groups, or gain broader
filesystem/device capabilities. AppArmor and package tests enforce that limit.

Immich is not included: its supported topology needs shared component secrets,
health-gated dependencies, bounded database shared memory, and database-aware
backup/rollback. Syncthing is not included because bridge networking does not
provide its supported LAN discovery topology, and host networking remains
prohibited. The archived original File Browser is replaced by maintained,
first-run-authenticated SFTPGo.

See the [media and data app guide](../media-data-apps.md), [catalog](../application-catalog.md), [trusted storage architecture](../architecture/trusted-storage.md), and [known limitations](known-limitations.md).
