# KITPro Server v0.1.0-alpha.14 release notes draft

Status: local development draft. No alpha.14 package, tag, or release has been
published.

## Added

- Managed nginx ingress with strict hostnames, catalog authorization, loopback
  backends, unknown-host rejection, and transactional generations.
- Administrator-provided certificates and a managed ACME HTTP-01 lifecycle.
- A durable nine-step first-run guide and typed readiness dimensions.
- Host-state backup semantics for ingress, certificates, ACME, setup state,
  and restore holds.
- Root-local administrator password recovery with global session revocation.
- Redacted support bundles for build, runtime, application, and ingress status.

## Security behavior

Ingress and HTTPS remain opt-in after an alpha.13 upgrade. Private keys are
root-owned and absent from ordinary API, UI, log, audit, and diagnostics
projections. KITPro does not claim that these secrets are encrypted at rest.

An invalid nginx candidate or certificate replacement cannot replace the last
known-good generation.

## Scope correction

Cloudflare Tunnel was evaluated during alpha.14 development and exposed useful
generic Host-isolation and ACME challenge-routing issues. Those generic fixes
remain. Tunnel provider configuration, runtime management, credentials, API,
packaging, and setup integration are deferred and are not alpha.14 features.

Managed ACME uses HTTP-01 and therefore requires public inbound TCP/80. Hosts
without that path can use administrator-provided certificates, including
certificates obtained through an external DNS-01 or upstream-proxy workflow.

## Platform policy

Debian 13, Ubuntu 26.04 LTS, and Arch Linux with `linux-lts` remain Supported.
Rocky Linux 10 remains Experimental. Alpha.14 does not broaden Rocky's
application lifecycle claim.

## Qualification status

The release remains blocked until fresh-install, published-alpha.13 upgrade,
mandatory-access-control, reboot, live ingress, and final-artifact gates pass on
their required platforms. This draft is not release evidence.
