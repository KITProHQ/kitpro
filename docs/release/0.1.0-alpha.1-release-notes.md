# KITPro Server 0.1.0-alpha.1

KITPro Server is a local-first application manager for people who want to
self-host useful services without handing a browser unrestricted Docker access.
This is a public alpha: expect rough edges and review the documented limits.

Highlights include authenticated setup and lifecycle controls, immutable
catalog images, installation-scoped persistent storage, controlled internal /
loopback / LAN exposure, multi-container Paperless-ngx support, native Debian,
Ubuntu, and Arch packages, AppArmor confinement, and validated update backups.

Supported platforms are Debian 13 amd64, Ubuntu 26.04 LTS amd64, and Arch
x86_64 with `linux-lts`, fully updated official repositories, rootful Docker,
and enforcing AppArmor. Rocky Linux 10 remains experimental.

The catalog contains FreshRSS, Uptime Kuma, Mealie, Memos, Actual Budget,
Vaultwarden, Home Assistant, and Paperless-ngx. No arbitrary Compose, user manifests,
HA/clustering, reverse proxy/TLS automation, or automatic disaster recovery is
included. Application data remains under `/srv/kitpro/apps` and is not silently
deleted by runtime removal or package removal.

Updates use native apt/dpkg or pacman. KITPro backs up its control/helper state
before package migrations; application-data backup is not automatic. Report
bugs with version, platform, logs scrubbed of secrets, and reproduction steps
through the repository issue process.
