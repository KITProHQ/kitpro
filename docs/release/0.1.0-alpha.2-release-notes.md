# KITPro Server 0.1.0-alpha.2

KITPro Server is a local-first application manager for people who want to
self-host useful services without giving a browser unrestricted Docker access.
This public alpha is not production-ready software; keep independent backups
and review the documented limitations before installing it.

Alpha.2 delivers the polished KITPro Server interface shown on the product
page and in the repository documentation. The dashboard, trusted catalog,
application management, access controls, updates, errors, responsive layouts,
and accessibility details now share one calmer and more approachable design.

Supported platforms are Debian 13 amd64, Ubuntu 26.04 LTS amd64, and Arch
Linux x86_64 with `linux-lts`, fully updated official repositories, rootful
Docker, and enforcing AppArmor. Rocky Linux 10 remains experimental.

The trusted catalog contains FreshRSS, Uptime Kuma, Mealie, Memos, Actual
Budget, Vaultwarden, Home Assistant, and Paperless-ngx. Paperless-ngx is
managed as one logical multi-container application. Application data remains
under `/srv/kitpro/apps` and is preserved when KITPro recreates a runtime.

Updates use apt/dpkg or pacman for KITPro itself and trusted catalog releases
for applications. KITPro backs up its control state before package migrations;
application-data backup is not automatic. See the quickstart, supported
platform guidance, security policy, backup documentation, and known
limitations before use.
